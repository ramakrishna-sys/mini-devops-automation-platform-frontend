# Mini DevOps Automation Platform – Frontend

A frontend web application developed as part of a team-based Mini DevOps Automation Platform project.

## My Contribution

- Designed and developed the frontend user interface.
- Developed the login, dashboard, build history, deployment, and health monitoring pages.
- Implemented frontend interactions for triggering builds and deployments.
- Connected frontend pages with backend REST APIs using JavaScript.
- Created responsive styling using CSS and Bootstrap.

## Features

- User Login
- DevOps Dashboard
- Build History
- Build Triggering
- Deployment Monitoring
- Deployment Triggering
- System Health Monitoring
- Backend Status Checking
- Database, Docker and Jenkins Status Display
- Responsive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- REST APIs
- Git
- GitHub
